# Archive

This directory preserves earlier experimental phases of the thesis project for history. None of it is required for the thesis-facing system (in the parent directory) to run.

## Contents

- **`prephd-benchmark/`** — a separate routing-benchmark project from before the thesis pivot (April 2024).
- **`stage-a-data/`** — parquet files, baselines, and checkpoints from the Stage A sufficiency benchmark (the pre-thesis research arc).
- **`stage-a-scripts/`** — runners and utilities from the Stage A benchmark.
- **`stage-a-experiment/`** — Run 1 era experimental code (generator, judge, classifier) and pre-thesis methodology docs. Note: `experiment/results_RUN1/generator/` at the repo root is NOT archived because current tests reference its fixtures.
- **`stage-a-reports/`** — Stage A predictor and baseline reports.
- **`prereg/`** — pre-registration documents from before the thesis was finalized.
- **`phase-b-engineering-log/`** — internal stage reports, comparative findings, and working notes from developing the operator-persona evaluation. The thesis prose does not reference these documents directly; the load-bearing thesis citations point to the in-tree paths under `product/evaluation/reports/`.
- **`spec.md`**, **`CLAUDE.md`** — older planning files.
- **`calibration_human_sheet_all_5.csv`**, **`human_scoring_patch.csv`** — Phase B human-calibration working files.

To inspect or revive anything in `archive/`, the contents are intact and unmodified; only the path changed.
